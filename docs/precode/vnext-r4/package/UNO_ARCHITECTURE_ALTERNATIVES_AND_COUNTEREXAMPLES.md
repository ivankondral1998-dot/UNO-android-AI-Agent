## Контрпримеры и различимые гипотезы

1. **Линейный trunk.** $w^TAx+b=(A^Tw)^Tx+b$. Даже после переобучения A итоговое разделение линейно. XOR на четырёх углах квадрата нелинейно разделим: диагонали классов пересекаются. Ручное переключение головы скрывает routing и не проверяет autonomous proposal.
2. **Свидетельство выразительности S4/S5.** При s=g=0 и I=∅ направим два сенсорных компонента x_i∈{−1,+1} в отдельные входные координаты W_sensor. Для прочих входов и U_s=0 получаем $z_i=c x_i$, $c=\tanh(\tanh 1)>0$. Для свободной выходной координаты j с z_j=0 возьмём две строки C по z1+z2, biases +1,−1, A=0. Строка B (.45,−.45) даёт $f_j=\tanh(.45[\tanh(S+1)-\tanh(S-1)])$, S=z1+z2. Разность чётна и строго убывает по S>0, потому что $\mathrm{sech}^2(S+1)<\mathrm{sech}^2(S-1)$, следовательно f_j выше для разных знаков. При общей полной маске и K1 $h_j^1=\alpha f_j$; другие ветви могут быть копиями. Нормы C≤2, B≤.9, A=0 допустимы. Одинаковые canonical argument events с нулевыми проекциями и фиксированным общим маршрутом в точной арифметике сохраняют порядок через $h_j^+ =\rho(1-\alpha)h_j+const$ при K1. S7 может разделить конечные h_a одним logit, используя общий constant q_R>u_min и threshold с положительным margin. Это существование представления для frozen path, не доказательство обучения, finite precision или autonomous verb choice. Для законного практического arm требуются обученные Θ, реальные canonical h_a и допустимый endpoint.
3. **Неполное покрытие условий.** OR и XOR совпадают, если не проверять (1,1). AND и константа 0 также совпадают на этих трёх случаях. AND и XOR сами не совпадают на (0,1)/(1,0). Проверить все сочетания, missing, конфаундер и ошибочные receipts. Два мира X→Y и Z→X,Y могут давать одинаковый X=Y без доказанного do-эффекта.
4. **P-only.** При frozen h_a максимум S7 равен $q_R\sigma(l_0+\|h_a\|)$; unreachable threshold и одинаковый trace для разных args не устраняются P1. Стабильность одного loss не предотвращает забывание. P-only не вызывать до lawful receipt. Не объявлять P/Θ arms испытанными по ручному toy.
5. **A.** Конфликтующие вклады могут давать ноль, signed feature hash коллизионен, выбор только Q_G slots пропускает релевантную запись. Сохранить exact scope и count, измерять recall против full scan, проверить TTL/expiry и watermark.
6. **B.** Локальная fixed-z оценка не даёт глобальной из-за branch jump, новые связи могут скрытно сделать весь graph projection дорогим. Отдельно проверять compiled kernel/skip, decoded norm, old-snapshot parity и graph perturbation.
7. **Перевод способностей между профилями.** Уменьшение rank/m/d не доказывает эквивалентность. Увеличение d с нулевым embedding сохраняет математическую функцию только при согласованном переносе всех heads, selector/rotations, masks, exact proposal/args, memory, calibration и resource regime. Без этого даже нулевой новый блок меняет q distribution и K. Новый snapshot проходит re-encode/fresh nonce и regression gates.

Критический тест нового навыка: одинаковый frozen corpus и бюджет для rule search/таблицы/синтеза с раскрытой грамматикой, fixed F, P-only/M-only/P+M и A/B. Разделить missing-feature, ID memorization, routing, истинный source of label, stage drift и перенос. Одинаковые наблюдения для всех arms, old-before и old-after на тех же независимых задачах. Случайная карта G или отключённый G — ablation. Тестировать paired task successes, отдельно authorized/verified/UNKNOWN, recovery, joules/latency/PSS; плохой baseline не доказывает преимуществ. Результаты N0 не использовать для ретюна и последующего «слепого» теста на тех же данных.
