# R5.2 — предлагаемые решения для владельца, не утверждённые автоматически

| Вопрос | Предлагаемая политика | Почему | Что остаётся проверить |
|---|---|---|---|
| WAKE/SENSOR | **Обязательны** в целевой архитектуре; использовать пути из `03` | Не урезать задуманный полноценный организм | Воспроизводимое обучение/датасеты, false-wake/hour, сенсорная достоверность, A52 idle |
| Нейронная маска | Cyclic-prefix — **первый проверяемый baseline**, arbitrary subsets — исследовательский comparator; не объявлять их эквивалентными | 241 и 65535 комбинаций; фиксированный общий путь допускает ограниченный proof | Equal-budget quality/resource comparison, selector-jump тесты |
| Выбор размера | B2-512, B2-1024, B2-1536 как кандидаты; 2048 контроль масштабирования, LR2/H2 только после ABI | Ни количество весов, ни MAC не доказывают интеллектуальную достаточность | Легальные данные и обучение, затем качество+память+латентность+джоули |
| Память | Semantic aggregate **плюс** exact retrieval из raw payload, без второго reasoning-мозга | Математически требуется для точного воспроизведения и конфликтов | Атомарность snapshot/revoke, retention/fault injection |
| Офлайн | Только `app-private` или верифицируемо локальные источники **по умолчанию**. Неизвестный сторонний SAF-провайдер → `UNSUPPORTED_OFFLINE_SOURCE` | UNO без INTERNET permission может косвенно инициировать remote fetch через provider | Android provider behavior / network monitor / device tests; прошлое происхождение файла не утверждается |
| Android authority | Техническая проверка действующих OS permissions, точного согласия/STOP/readback вне нейросети | Модель не может самостоятельно разрешать себе опасные действия | Native effect/rollback/overlays/owner identity; **старый Jarvis OwnerGate не является требованием** |
| Пороги качества | До первого обучающего эксперимента оставить кандидаты ASTRA D01, выбрать независимые oracles и статистическую процедуру | Избежать подгонки под результаты; не делать вид, что все цифры доказаны | Утверждение владельцем перед locked test, набор данных и мощность выборки |
| Энергия | Измерять реальный эффект на Samsung A52; запрещено утверждать «экономнее» по MAC | DSP, памяти, драйверам и ОС требуются калибровки | PSS/p95/idle/thermal/physical joules |

## Что можно закрыть без владельца

Формальное исправление W4, неоднозначность memory-aggregation, exact retrieval **как проект API**, арифметика политик масок, обязательная фиксация источников данных и проверок, причинная граница STOP, разделение MAC от Joules.

## Что не подменяем решением автора

Владелец выбирает product-scope (WAKE/SENSOR required), acceptable UX/security/energy thresholds и архитектурные компромиссы; разработчик не может выдать свои предложения за подписанное решение. Реальные trained Θ, device PASS, licensed data и quality gates не выводятся из математических чертежей и выполняются/проверяются позднее, при разрешённой разработке.

## Предлагаемая короткая формулировка решения владельца (не подписана)

«Принимаю для подготовки окончательной предкодовой редакции: WAKE и SENSOR обязательны; B2 с циклическими масками — первая проверяемая конфигурация, а не гарантированно лучшая; semantic память дополняется точным retrieval; обработка полностью локальна; реальные веса и измерения остаются предметом этапа реализации. После независимого review отдельно решу, утверждать ли UNO PRE-CODE BASELINE».
