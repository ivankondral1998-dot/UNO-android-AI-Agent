# Адресные исправления статусов и ложных предположений агентов

1. «V01–V20 отсутствуют»: **неверно для пакета vNEXT-R4**; `package/evidence/v_sources/` содержит 20 оригиналов, посчитаны SHA-256. ИСТОРИЧЕСКИЕ сообщения об их отсутствии относятся к более ранним контейнерам. Исторические документы не править; использовать `package/ERRATA_R4.md` §R4-01.
2. «У UNO нет испытаний A52»: неверно, если речь обо всех экспериментальных N0-03–N0-07. В журнале research есть reported physical tests; при этом это не полноценная end-to-end система UNO. Нужны provenance и scope каждого набора данных.
3. «Математика и документы не готовы»: некорректно для **завершённых артефактов Astra/R4.1/R3/R4**. Эти документы разработаны; G4 owner approval и полнота формальной валидации — отдельные события. Самостоятельная повторная рецензия не может перевести статус работы в «несуществующую».
4. «Нет обученных весов»: некорректно как универсальное высказывание — были малые experimental weights (N0-07, 2,917); корректная формулировка: **нет проверенных обученных production UNO weights / утверждённого checkpoint**.
5. «G4 утверждён»: неверно. Историческое `APPROVED` агента не равно owner approval; `OWNER_APPROVED_PRECODE=FALSE`, `PRODUCTION_CODE_AUTHORIZED=FALSE` до нового явного решения.
6. «N0-07 полностью отрицателен / вся UNO невозможна»: неверно. N0-07 имеет конкретный отрицательный frozen-fixture result, не физический или математический запрет проекта.
7. «V14/V19/V20 PASS»: только узкие оригинальные фикстуры. R4 показывают непроверенные граничные условия: V14 forged cursor, V19 stale outbox after boot, V20 one token double ACCEPTED. Новые контракты SPECIFIED_UNTESTED до независимых реализаций.
8. «OFFLINE = отсутствует INTERNET permission»: недостаточно: сторонний SAF provider может обращаться к сети. Проверять фактическое поведение и доверенную границу Android.
9. Для `UNKNOWN/MAY_HAVE_EXECUTED` нельзя слепо повторять команды. STOP не отменяет уже состоявшиеся эффекты. Использовать независимый native readback и одноразовые тикеты.

Правило рецензирования: сначала путь + SHA + версия + условие теста; потом `PROVEN_LOCAL / CONDITIONAL / SPECIFIED_UNTESTED / REQUIRES_DATA / OWNER_DECISION / FAIL`; неизвестное не подменять отсутствующим.
