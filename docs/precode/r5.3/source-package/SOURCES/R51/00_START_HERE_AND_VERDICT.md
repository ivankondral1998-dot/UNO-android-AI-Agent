## Итог сверки
- R1/R2: все 11 позиций присутствуют. Только R1-03 отмечен `PROVEN_LOCAL`; прочие `CONDITIONAL`/`REQUIRES_DATA` при указанных предпосылках. Нельзя говорить «все R1/R2 доказаны».
- IR01: контрпример корректен; R5-Δ01 даёт условно верное верхнее ограничение для одинаковых фиксированных масок. Добавлен конструктивный контрпример state-dependent mask (см. `02`). Исходная W4 формула остаётся неотредактированной, значит нормативное исправление **ещё не принято**.
- IR02: noninjective aggregation доказана; R5-Δ02 только предложение. Здесь конкретизирован типизированный контракт ограниченного извлечения с режимами `COMPLETE/CONFLICT/TRUNCATED/UNKNOWN`, без обещания безошибочного recall (см. `03`).
- IR03…IR08: расхождения описаны и сданы на решение/данные; ни один hardware/security/data gate не объявляется PASS.
- Сохраняются границы: память≠разрешение; STOP до dispatch не разрешает новое действие, но не отменяет уже отправленный effect; receipt≠causal impact; host-test≠Android proof.
