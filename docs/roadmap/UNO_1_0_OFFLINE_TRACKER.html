UNO 1.0 — трекер разработки

Полноценный локальный Android-агент: собственное нейросетевое ядро, память, доверенный контур Android, тесты A52 и будущий коммерческий выпуск. Без онлайн-изменения весов.

Это рабочий план, не доказательство выполнения. Отметки хранятся в этом браузере и могут пропасть при очистке данных. После каждого этапа нажимай «Сохранить прогресс JSON» и храни экспорт отдельно. Единые правила находятся только в AGENTS.md. Трекер не запускает обучение, сборки, GitHub Actions и не синхронизируется с GitHub автоматически.
