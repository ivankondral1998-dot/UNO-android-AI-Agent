# UNO 1.0 — дорожная карта и контроль исполнения

> **Исполняемый план, не набор правил.** Действующие полномочия только в [корневом AGENTS.md](https://github.com/ivankondral1998-dot/UNO-android-AI-Agent/blob/main/AGENTS.md). При конфликте побеждает актуальное явное решение владельца; старые исследования не становятся требованиями автоматически.

**Версия:** `R10-EXEC-2026-11-07-01`. **Зафиксированный стартовый SHA рабочей ветки:** `8744f9013cb90fbd5eb9b0b1b570c91c4367c43f` (перед изменением проверить текущий HEAD).

## Стартовая приёмка и ограничения

**GO:** Android, A52 измерения, CPU-reference единого F, безопасный контроллер, память и подготовка собственных весов. **NO-GO:** существующие веса как коммерческий интеллект, производственное обучение без разрешения, опасные действия и релиз.

### Не подменять доказательства

- **PROVEN_LOCAL_INTEGRITY:** R5.3 63/63 и Astra 116/116 SHA-инвентаризация. **Ограничение:** Не математическая истинность всех теорем.
- **PROVEN_LOCAL_ARITHMETIC:** B2 198 tensors; d1024 55,451,639 allocations; F K8 138,412,032 MAC. **Ограничение:** Не выбран продуктовый размер, не скорость A52.
- **FAIL_UNIVERSAL:** R5.3 adaptive mask global contraction. **Ограничение:** Частная оценка fixed common mask остаётся.
- **FAIL:** Semantic recall is exact memory. **Ограничение:** Нужен raw exact retrieve и provenance.
- **HOST_TESTED_PRIOR_AUDIT:** LAB-031/032 host simulations. **Ограничение:** Синтетика и ceiling effect, не интеллект.
- **DEVICE_OWNER_REPORTED_FAIL_UTILITY:** N0-07 A52 frozen valid stages 38/160 vs persistence 117/160. **Ограничение:** Нет прямой ADB в этой сессии.
- **HOST_TRAINED_HISTORICAL_FAIL:** FR/TR first training 0/32 exact-match unseen names. **Ограничение:** Не полноценная языковая модель.
- **HOST_TESTED:** ControlEvents Kotlin primitive host PASS. **Ограничение:** STOP/native dispatch TOCTOU остаётся.
- **NOT_IMPLEMENTED:** Полный UNO 1.0 APK/интеллект. **Ограничение:** Отсутствует.

## Зависимости критических путей

Android: WP-00 → WP-01 → WP-02 / WP-03 → WP-05 → WP-06 → WP-07 / WP-08 → WP-09.
Интеллект: WP-00 → WP-04 (данные, evaluation) одновременно с WP-01/WP-03 → **отдельное решение владельца** на обучение → собственный замороженный checkpoint → WP-06.
Публичный сайт WEB-01 ведётся параллельно и никогда не является сервером/памятью UNO.

## Протокол работы агента

1. Сначала прочитать main/AGENTS.md и снять фактические HEAD/branch SHA.
2. Обновлять задачи по одной: issue/commit, source, тест, stdout/stderr+exit code, SHA артефактов, устройство и пределы проверки.
3. Статусы выполнения и уровни доказательств независимы. Host PASS ≠ Android build ≠ phone verification.
4. До производственного обучения получить явное отдельное решение; никакого online-обучения в UNO 1.0.
5. Вести прогресс в офлайн HTML, регулярно **экспортировать JSON**; для долговечности коммитить проверенный export на разрешённую рабочую ветку (не автоматически).
6. При ошибке исходных формул создавать адресное версионированное erratum, сохранять оригинал. Никогда не удалять историю.
