# UNO: «Профессор + ученик» — отдельный эксперимент, 7 ноября 2026

**Итог: FAIL для заранее заданного критерия.** Объединение пока не стало лучше сильного одиночного варианта. Это **HOST_TESTED_SYNTHETIC_ONLY**: не полноценный нейронный организм, не тест на интеллектуальность и не измерение Samsung A52.

## Кратко

Мы проверили именно идею двух функционально разных частей, а не просто две скорости изменения одних весов:

- «**Профессор**»: ранее обученная сеть на старом правиле A, на новом контрольном наборе **94,06%** правильных решений. Её веса заморожены при совместном обучении.
- «**Ученик**»: отдельная обучаемая нейросеть, принимающая **признаки из скрытого состояния профессора**, исходные наблюдения и краткую общую память по подтверждённым исходам. Она вычисляет поправку к **единственному** решению. Её обучение не изменяет веса профессора.
- Оба связаны внутри одного оператора выбора действия, **не являются двумя независимыми агентами и не получают Android-полномочий**.

Сравнили на **36 заранее заданных мирах**: по 12 с похожим правилом, противоположным правилом и новой комбинацией признаков. В каждом было 160 действий и только задержанный на три шага исход выбранного действия. Всего **5 760 исходов на метод**, 8 основных методов; 9-я строка — отдельная диагностика переноса весов, без собственной онлайн-фазы.

## Основные цифры

| Условия | Метод | Онлайн-потери (меньше лучше) | Старый A после обучения | Новый B | Перенос B на другие входы |
|---|---|---:|---:|---:|---:|
| **Похожие правила** | Замороженный профессор | 0,0948 | 94,4% | 80,1% | 82,8% |
| | Обычная сеть + повторение A | **0,0905** | 91,1% | **83,3%** | **85,4%** |
| | Профессор + ученик | 0,0932 | 91,9% | 82,1% | 84,1% |
| | Ученик без профессора | 0,1284 | 68,8% | 74,9% | 77,1% |
| **Противоположные правила** | Обычная сеть + повторение A | 0,3163 | 84,4% | 28,4% | 28,6% |
| | Ученик без профессора | **0,1249** | 31,1% | **73,4%** | **74,5%** |
| | Профессор + ученик | 0,2464 | 26,8% | 69,3% | 70,7% |
| | Профессор + ученик после переноса в долговременные веса | — | 77,3% | 33,2% | 34,8% |
| **Новые комбинации** | Обычная сеть + повторение A | 0,1754 | 89,7% | 54,8% | 53,0% |
| | Профессор + ученик | 0,1721 | 66,7% | 54,5% | 57,1% |
| | Простая таблица | **0,1375** | 53,3% | **67,0%** | **68,0%** |

Числа — средние по 12 независимым фиксированным семенам на условие. **Проценты означают выбор более выгодного из двух действий по моделируемому закону среды**. Это не «процент интеллекта», и здесь нет обработки русского языка, памяти жизни или реальных Android-действий.

### Что показал результат

1. **На похожих задачах** совместная сеть переносит старый навык, но уступает более простой сети с повторением старого опыта. Парное преимущество совместной по онлайн-потерям относительно replay = **−0,0027**, 95% бутстрэп-интервал **[−0,0044; −0,0013]** (положительное значение означало бы преимущество объединения). Следовательно, в данном опыте проигрыш повторяется, а не вызван одной случайной задачей.
2. **При перевороте правил** «ученик» может выучить новое, но его поправка перекрывает решения «профессора». Старые веса остаются сохранными, однако **старый навык практически теряется в поведении**: 26,8% на A после B. Это реальный дефект способа объединения, не порча самих сохранённых весов.
3. **На принципиально новых сочетаниях признаков** простая таблица дала онлайн-потери 0,1375 против 0,1721 у объединения. Следовательно, сложность двух нейросетей не окупилась даже на этой небольшой задаче.
4. **Перенос навыка из ученика в старые веса** не решил конфликт: в перевёрнутых мирах после переноса A вырос до 77,3%, но B упал до 33,2%. Нельзя объявлять успешную интеграцию новых знаний.
5. Вариант ученика **без скрытых признаков профессора** местами показывает лучший онлайн-результат, чем основной вариант с ними, но ещё сильнее теряет старый навык. Это сигнал для исследования взаимодействия, не окончательный вывод о полезности скрытых признаков.

**Критерий успеха был зафиксирован до запуска** в `PROTOCOL_LOCK.json`: требовалось улучшить похожие задачи по онлайн-потерям и переносу, сохранить A, не ухудшить перевёрнутые правила и подтвердить разницу интервалом. **FAIL: 3 из 6 проверок не пройдены**. Протокол и SHA в `PROTOCOL_LOCK.sha256`.

## Как именно устроен опыт

- Источник «профессора»: числовые веса из **прошлого** эксперимента `UNO_DUAL_CAPABILITY_EXPERIMENT_20261107`. Оригинальный сохранённый файл **вложен без изменений**: `provenance/SOURCE_SLOW_PRETRAINED.pt`, SHA-256 в протоколе. Старое предварительное обучение не проводилось заново, но новый независимый контроль A выполнен.
- Вход: 4 числовых признака. Действия: +1 / −1. Среда задаёт вероятность успеха выбранного действия, а агент получает **только его фактический бинарный исход**, не исход отвергнутого действия. Распределения и формулы среды находятся в `src/experiment.py`.
- Онлайн-обучение: до 160 подтверждённых симулятором последствий на каждую модель, доставка с задержкой 3 шага; на шаге выбора — 25% случайных исследовательских действий. Данные из будущего и истинный закон среды не подаются обучаемой сети.
- Метрики считаются по независимым контрольным наборам, а онлайн-потери — по известным оценщику вероятностям успеха обеих действий. **Знание обеих вероятностей доступно только оценщику**.
- Сильный контроль: обычная сеть с тем же исходным «профессором», дообучаемая на новых исходах с повторением искусственных событий A. Другие контроли: замороженный профессор; та же сеть без повторения A; ученики с нуля (двух размеров); совместная сеть без внутренних признаков учителя; таблица.
- После онлайн-этапа проведено отдельно **80 шагов дистилляции**: обучаемую копию «профессора» пытались обучить предсказаниям объединения и старому состоянию A. Дистилляция не получает правильных решений B от всезнающего оценщика. Она оформлена как отдельная диагностика.

## Проверка честности и воспроизводимости

- До первого запуска создан файл `PROTOCOL_LOCK.json` и SHA-256; не является внешней временной печатью.
- Первая попытка закончилась ошибкой: копию профессора при дистилляции забыли разморозить. Журнал: `logs/first_attempt_failed.stderr`. Ошибка исправлена **до получения полных результатов**, условия испытаний и критерии успеха не менялись.
- `src/test_contracts.py` проверяет единое решение, реальное влияние ученика на выход, неизменность веса профессора, блокировку неподтверждённой обратной связи и доставку всех отложенных результатов. Все проверки прошли.
- `src/verify_results.py` независимо пересчитывает все средние, парные различия, доверительные интервалы и итоговый FAIL из `results/RAW.json`, проверяет SHA входных весов и протокола.
- `src/export_trained_example.py`: отдельно переигрывает первое фиксированное испытание и сохраняет **4 реально обученных `state_dict`**, которые затем загружаются через `torch.load(..., weights_only=True)`. Предсказания и веса после перезагрузки совпали.
- `src/clean_replay.py`: повтор **всего эксперимента из чистой временной директории**, без изменения исходных файлов. `RAW.json` совпал побайтово, `SUMMARY.json` совпал за исключением фактического времени выполнения. Отчёт `results/CLEAN_REPLAY_VERIFICATION.json`.
- GitHub, `main`, Actions, Android и старые ZIP не изменялись. Это локальный исследовательский эксперимент, одобренный текущей командой владельца, **не разрешение на обучение основного UNO**.

## Слабые стороны эксперимента

- Это очень простой вероятностный симулятор с **двумя действиями**, а не проверка общего интеллекта, понимания причинности, языка или собственной инициативы.
- Активные параметры и реальные затраты вычислений **не равны**: у объединения 335 коэффициентов (169 замороженных + 166 обучаемых), у обычной сети — 169 обучаемых, и отдельная сеть replay использует старые события A. Нельзя утверждать превосходство при одинаковом энергобюджете.
- Использованы заданные вручную архитектуры, скорости оптимизации и три семейства законов среды. Нет полного поиска настроек, независимой репликации другим исследователем, лицензированных жизненных данных или реальных сенсоров.
- При A и B можно применять разные функции успеха; задача не требует полной идентификации причинной структуры из пассивного наблюдения.
- Независимость последствий означает независимость **симулятора от ответа модели**, а не подлинный Android readback. Нет измерения батареи, RAM/PSS, тепла и скорости на Galaxy A52.
- Прямое обновление весов и совместная быстрая память заданы разработчиком. Автоматическое развитие новых когнитивных функций, автономная память и пластичность полной модели UNO не доказаны.

## Исполнение

Из копии каталога при наличии Python 3, PyTorch и NumPy:

```sh
python src/test_contracts.py
python src/experiment.py
python src/verify_results.py
python src/export_trained_example.py
python src/clean_replay.py
```

`experiment.py` перезаписывает **только собственные** файлы `results/RAW.json` и `results/SUMMARY.json` в копии. Для воспроизводимости сохраняйте `PROTOCOL_LOCK.json`, исходный `SOURCE_SLOW_PRETRAINED.pt` и версию кода из архива. `clean_replay.py` работает в новой временной копии. Никакие внешние API не нужны.

**Инженерное решение:** это **провал конкретного метода соединения**. Перспективный вопрос на следующий шаг — как сохранить полезный старый навык при обучении быстрой поправки, не мешая новому. Но сначала надо нормировать бюджет и исключить тривиальные контрольные алгоритмы.
