# UNO — второй опыт «профессор + ученик»: проверка приобретения и переноса навыка

Дата: 2026-11-07. **HOST_TESTED_SYNTHETIC_ONLY. Критерий принятия не пройден; новая архитектура UNO не утверждена.**

## Итог в двух абзацах

Проверили **одну общую сеть с двумя скоростями изменения коэффициентов**. Медленная часть заранее изучила старое правило A («профессор»); быстрая часть получала подтверждённые результаты собственных действий в новом мире B («ученик»). После накопления опыта мы пытались закрепить навык B в медленной части и обнулили временные веса. Это не два автономных мозга; решение принимает сумма двух вычислений одной модели.

На 20 независимо заданных новых правилах **объединённый вариант лучше сохранил старую задачу**, но **хуже освоил новую и хуже перенёс её на невиданные состояния**, чем обычная предобученная сеть, дообученная на новом и повторённом старом опыте. Поэтому перенос навыков не оправдал усложнение в этом опыте.

| Стратегия | Точность старого правила A после B | Точность нового B | Новый B, изменённое распределение x | Regret онлайн (меньше лучше) |
|---|---:|---:|---:|---:|
| Медленная сеть без обучения | 94,8% | 61,4% | 67,7% | 0,2018 |
| Обычная сеть, старт с нуля и обучение B | 63,3% | 80,4% | 84,0% | 0,1269 |
| Предобученная, обычное дообучение B | 73,5% | 81,7% | 85,7% | 0,1162 |
| **Предобученная с повторением A+B** | 88,7% | **84,1%** | **86,2%** | **0,1162** |
| Медленная+быстрая без закрепления | 70,7% | 78,5% | 82,1% | 0,1267 |
| **Медленная+быстрая с закреплением и обнулением быстрых весов** | **93,2%** | 77,7% | 82,2% | 0,1267 |
| Простая таблица признаков | 50,1% | 75,1% | 77,4% | 0,1547 |

Таблица: метрики **после 128 событий B и после 150 обновлений закрепления/повторения** (если они предусмотрены стратегией). Regret — в течение 128 событий B, до отдельного закрепления. Это средние 20 фиксированных синтетических задач. Отдельное число удачных действий не равно оценке интеллектуальных способностей.

Параллельные сравнения dual minus single_replay на 20 одинаковых мирах, бутстрэп 95% **только для этого симулятора**: старое A **+4,49 процентного пункта** [2,71; 6,88], новое B **−6,37 п.п.** [−8,60; −4,26], перенос B **−3,98 п.п.** [−5,98; −1,64].

**Заранее зафиксированный критерий не пройден:** требовалось сохранить старый навык почти на уровне замороженного профессора и одновременно превзойти обычную сеть с повторением на B и переносе минимум на 3 п.п., с положительными парными интервалами. Только первая часть выполнена.

## Что именно испытывали

- Синтетическая среда: четыре непрерывных признака и видимый режим A/B; вероятность успеха действия зависит от нелинейных взаимодействий признаков. Агенту доступны только его выбранное действие и результат, полученный **через три шага**; вероятность другого действия и скрытое правило видны только оценщику.
- Медленная сеть: `5→24 tanh→1`, 169 коэффициентов. Быстрая поправка: `5→12 tanh→1`, 85 коэффициентов. Всего 254 обучаемых числа в двойной архитектуре. Прогноз — сумма выходов, одно решение.
- Подготовка: 6000 синтетических событий A, 420 обновлений на медленной сети. Затем 20 новых B-миров, в каждом 128 событий и 20% исследовательских действий. Для части миров правило частично перевёрнуто. Возврат к A и проверка B выполняются **на отдельном неизменяемом наборе 768 состояний на каждый режим**, включая сдвинутое распределение признаков.
- «Закрепление»: быстрая сеть обучается по 128 поступившим проверенным результатам; затем из зафиксированной версии её предсказаний и сохранённых данных A/B обучается медленная сеть за 150 обновлений, после чего быстрая часть обнуляется. Для честного сильного контроля обычная сеть получает те же 150 дополнительных обновлений на том же A+B.
- Нет готовых правильных ответов для действий в онлайн-обучении; используются реально выбранные действия и независимо сгенерированные симулятором исходы. Счётчик `verified` — **только симуляторный**, не нативный Android readback.

## Достоверность

1. `PROTOCOL_LOCK.json` создан до первого запуска и имеет локальный SHA-256 `3d2cba7343593ea852959abf8f2f2e13c48a0d69e65bda660370495382f582f4`. Это не внешняя криптографическая фиксация времени.
2. **Первый запуск оказался дефектным:** перенос в медленную сеть использовал подвижную цель, которая сама изменялась с сетью. Он сохранён только как недействительный диагностический журнал `logs/initial.stdout`. Исправлено сохранением неизменяемой копии обученного «ученика». В `logs/fixed.stdout` и `logs/final.stdout` — правильные запуски; опубликованные числа получены после исправления. Исходники не подменены молча; история ошибки здесь сохранена.
3. Пять контрактных тестов в `src/test_contracts.py` прошли. Пересчёт `results/RAW.json` по 140 записям (20 миров × 7 стратегий) — `VERIFICATION_PASS`.
4. Полный повтор из новой чистой директории: файлы `RAW.json`, `SUMMARY.json` побайтово совпали; числовые тензоры предобученных весов совпали (загрузка через `torch.load(..., weights_only=True)`). `results/CLEAN_REPLAY_VERIFICATION.json`.
5. Источники: `src/run_experiment.py`, `src/verify_results.py`, `src/test_contracts.py`, логи и исходные числовые результаты в архиве. GitHub не изменялся.

## Чего этот эксперимент НЕ доказывает

- **Не доказаны ни сознание, ни мышление, ни причинное понимание.** Это маленькая сеть с заранее выбранной задачей и заранее заданным человеком механизмом закрепления.
- Это **не полный оператор F UNO**; нет общей долговременной графовой памяти, восприятия, самостоятельного планирования, Android-действий, STOP/readback, реальной энергии A52 или обученной языковой модели.
- У соперников не полностью равное число параметров: объединённая конструкция 254, обычная модель 169. Число обновлений сопоставимо, но точные MAC/вычислительное время не нормированы. Поэтому результат нельзя переносить на сравнение весовых архитектур без отдельного эксперимента.
- В режиме B сигнал типа задачи известен по входному признаку. Модель не обнаруживала скрытую идентичность задачи. Смена правил не равна произвольной открытой среде.
- При накоплении данных о результате нейросети нет отдельных доказательств сохранности исходных телефонных событий: это самостоятельная тестовая среда.
- Закрепление прошло через имитацию предсказаний после обучения и повтор старых событий: это лишь один вариант способа соединения «учителя» и «ученика», **не опровержение любых двухскоростных архитектур**.
- Нет права назвать исследование G4/G5/UNO release готовым продуктом. Допуск к дальнейшему production training не следует из этого опыта.

## Запуск

Требуются Python 3, PyTorch CPU, NumPy. Команда в копии директории:

```sh
python src/test_contracts.py
python src/run_experiment.py
python src/verify_results.py
```

`run_experiment.py` перезаписывает только файлы `results/` в рабочей копии, не трогает GitHub. При загрузке `SOURCE_SLOW_PRETRAINED.pt` используйте `weights_only=True`.

**Решение по UNO:** `FAIL` для заранее заданного критерия превосходства; `SPECIFIED_UNTESTED` для полноразмерной реализации UNO; `REQUIRES_DATA` для реальной памяти, причинных механизмов и телефона. Не выбираем dual как новую архитектуру без доказательств.
