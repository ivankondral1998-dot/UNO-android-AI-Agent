# Исходное поручение владельца, сохранённое без упрощения

UNO — единый, локальный, автономный нейронный организм с новыми весами, общим состоянием и общим оператором F. Его цикл: наблюдение → выбор вычислений → память и изменение состояния → решение → разрешённое действие → **независимо наблюдённый результат** → обучение. Android — основная продуктовая среда; Samsung Galaxy A52/Android 14 — первая физическая платформа, но не предел архитектуры.

Обязательные свойства: offline без обязательного облака/API/OAuth/интернета, ограниченная память с разграничением точного retrieval и смыслового summary, энергоэффективные реальные skip вычислений, online пластичность с защитой старых навыков, модель авторизации/подтверждения Android и STOP, native readback, проверяемая причинность и сохранение свидетельств. Никакого набора отдельных мозгов, Bridge/BrainPort, переносов прежних весов Jarvis в новый мозг. Данные владельца, события датчиков и проверенные постусловия Android — **три разных типа обучающих сигналов**. Память не предоставляет разрешений; посланная команда не доказывает результата; подтверждённое конечное состояние само по себе не доказывает причинность.

Контрольная точка на 2026-11-06: `G4 PRECODE_CANDIDATE`, `OWNER_APPROVED_PRECODE=FALSE`, `PRODUCTION_CODE_AUTHORIZED=FALSE`; разрешены изолированные **исследовательские** эксперименты с малыми весами в соответствующей ветке по прежним решениям владельца, но не утверждение архитектуры для продукта и не обучение окончательных весов. O01–O08 остаются решениями владельца. GitHub `main` запрещено менять без отдельного указания, как и удалять исходники, переписывать историю, force push, запускать Actions без нового явного разрешения.

Новая корректировка владельца (2026-11-06): нельзя учить крошечную случайную модель на движениях и выдавать её за мозг UNO; смысл практической задачи важнее угадывания акселерометра. Следующий ориентир — интеграция математического каркаса R5.3 и событийно-причинной нейронной организации с **настоящей начальной базой/предварительным обучением**; фонарик рассматривать как полезный будущий экзамен «намерение → доверенная команда → readback → опыт», а не как захардкоженную кнопку и не как уже разрешённую реализацию.
