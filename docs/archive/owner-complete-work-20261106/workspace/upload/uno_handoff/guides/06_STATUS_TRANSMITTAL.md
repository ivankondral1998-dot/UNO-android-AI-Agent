# Состояние передачи / производные артефакты

Упаковка создана локально 2026-11-06. Она не утверждает, что GitHub — полное зеркало чата, или что все исходники проекта во всех ветках проверены. Запись в GitHub изменений не меняет состояния model production approval.

Постоянные данные: см. `RAW_FILES_SHA256.json` для всех файлов в этом ZIP. Вложенные архивы сохраняются в исходных байтах. `FILE_SOURCES.json` фиксирует происхождение. GitHub HEAD был зафиксирован перед архивной загрузкой и будет дополнен отдельно в commit audit; для актуального HEAD нужен повторный запрос к GitHub перед началом Work.

Проверки текущей упаковки: ZIP CRC через `ZipFile.testzip()`, SHA256 вложенных файлов, проверка ожидаемых локальных исходников и чтение report; НЕ полные реран тестов на Android. Ни одной нейросети на устройстве повторно не обучали.
