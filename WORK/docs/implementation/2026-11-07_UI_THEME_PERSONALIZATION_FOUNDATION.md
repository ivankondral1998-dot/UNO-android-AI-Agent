# UNO UI-01 — адаптивные темы по запросу владельца (кандидат и первые исходники)

Дата: 2026-11-07. Область: UNO 1.0, локальный Android UI. Действующие правила только `/AGENTS.md`.

## Решение пользователя

Оранжевый базовый интерфейс, также допустимы жёлтый и розово-голубой. Человек может вручную выбрать тему. Дополнительная функция: человек спрашивает UNO «какой цвет мне выбрать?», и UNO предлагает оформление, учитывая добровольно разрешённые сведения о предпочтениях и стиле общения. Возможна композиция нового оттенка, а не только выбор одного из трёх пресетов. Никакого сетевого сервера или передачи данных на сайт.

## Исполняемая граница

1. `UnoThemeGate` — контроллер локальной презентационной настройки. Он не является вторым интеллектом и не выдаёт permissions.
2. Когда появится принятая модель, **единое** F формирует `UnoThemeProposal` с локально вычисленным RGB, режимом DARK/LIGHT и краткой безопасной причиной. Изначально нейро-источника нет: никакой имитации «личного вкуса UNO».
3. Использование **сигналов стиля общения** требует предварительного явного согласия (`conversationStyleConsent=false` по умолчанию). Не анализировать скрытно историю, не выводить чувствительные личные характеристики, не привязывать суждения о личности к цвету. Запись сырого разговора для этой функции не требуется.
4. Пользователь сначала запрашивает совет; нейро-выбор только ставится в ожидание. Тема **применяется после подтверждения**. Владелец может отклонить, переключить вручную или запретить анализ стиля; ручное переключение аннулирует ожидающее предложение.
5. Доступность: предложенный произвольный RGB автоматически адаптируется к фону для контрастности текста >=4.5 по формуле относительной яркости sRGB; критический красный STOP не перекрашивается под настроение.
6. Сохраняется только текущая выбранная тема и флаг согласия в app-private `SharedPreferences`; нет сети/датасета профилирования/обновления весов. Не сохранять raw-текст чата в профиле оформления.

## Что уже в коде

- `android/core/src/main/kotlin/org/unovyra/uno/core/ThemePersonalization.kt`: proposal, consent, confirm/decline, override, color contrast.
- `android/core/src/test/kotlin/org/unovyra/uno/core/ThemePersonalizationTest.kt`: 62 независимых assert на host; `host_verify.sh` всего 100 проверок.
- `android/app/src/main/kotlin/org/unovyra/uno/UnoActivity.kt`: ручной выбор оранжевой, жёлтой, розово-голубой и светлой оранжевой темы; локальное сохранение; явный consent-toggle без чтения текущих разговоров; при отсутствии модели кнопка честно пишет, что совет недоступен.

## Не создано / требуется дальнейшая проверка

- Нейросетевой inference по тексту беседы, learned style hints, формирование рекомендаций F; модель/веса отсутствуют.
- Интеграция F с `UnoThemeGate.suggest()` и UI-подтверждением; должна быть после интеллектуальной приёмки, без самовольной смены темы.
- Полноценная двухцветная rose-cyan тема в визуальном дизайне (пока базовый розовый акцент).
- Android build, UI screenshot/instrumentation, Android 14 на A52, WCAG/focus/large-text acceptance. Проверка JVM-кода не равна сборке APK.

## Проверка

Запустить `cd android && bash scripts/host_verify.sh`. Ожидается `UNO_THEME_HOST_PASS=62` и `UNO_WP01_HOST_PASS=100`; это факт для host-прогона 07.11.2026, не device test.

При выпуске обязательно испытать: запрет при отсутствии согласия; отсутствие скрытого изменения цветов; ручное переопределение; отзыв согласия; восстановление темы после перезапуска; контраст и доступность; отсутствие сетевой активности; нейровыбор на свежих сценариях и реальном A52.
