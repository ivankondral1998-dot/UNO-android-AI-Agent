# UNO / UNOVYRA — единый вход для агентов (интеграционный кандидат)

**Прочти этот файл, затем основной [AGENTS.md](AGENTS.md), затем [WORK/STATUS.md](WORK/STATUS.md).**

Это **ОДНА рабочая Git-ветка с двумя областями**, а не новый проект и не новая архитектура:
- **[WORK/](WORK/README.md)** — Android-приложение, ядро F, безопасность, рабочие тесты и технические заметки.
- **[RESEARCH/](RESEARCH/README.md)** — оригинальные математические контракты, Grok/Terra, код обучения как исследование, эксперименты, аудит и история.

**Ключевой принцип:** один интеллектуальный F, общее состояние и память; Android authority/STOP/readback отделены от нейросети. Не заменять UNO GGUF-чатом, Jarvis, Bridge/Orchestrator или классификатором. Статусы в документах не означают выполненных здесь тестов.

Это интеграционный **структурный кандидат**. Он составлен из проверенных по SHA Git-объектов разных веток, но **совместимость компонентов, host suite, Android build и A52 на этом совмещённом дереве ещё не доказаны**. Никакие production-веса здесь не подключены и не обучались.

**Порядок чтения агентом:**
1. main/AGENTS.md — текущие полномочия; затем этот README.
2. WORK/STATUS.md — фактическая исходная точка, пробелы и зафиксированные SHA.
3. WORK/android/ — код и тесты; прежде чем менять, искать существующую реализацию.
4. RESEARCH/source-r53/ и RESEARCH/terra/ — проверить применимые формулы; RESEARCH/udc/ — причинный цикл; RESEARCH/train001/ — только исследовательская линия.
5. RESEARCH/BRANCH_INDEX.txt — все сохранённые ветки/HEAD. К старой ветке обращайся для происхождения, **не** для произвольного выбора новой основы.
6. Исправление — минимальное, обратимое, с тестом и точным SHA. Нет запуска GitHub Actions, merge в main, удаления веток, обучения весов, релиза без соответствующего решения.

**Работа с кодом:** `cd WORK/android` и только затем запускать существующие Android/host проверки. Gradle/Android-проект **не** лежит в корне. Подключение submodule llama.cpp перенесено в .gitmodules по пути WORK/android/third_party/llama.cpp.

**Важно:** существующий main пока НЕ заменён этой веткой. Старый main и другие ветки сохранены, подлинные источники не перезаписаны.
