# Локальные результаты аудита, 12.11.2026

- `source_pin_manifest.json`: побайтовый Git blob SHA и SHA-256 233 полученных текстовых источников из трёх зафиксированных commits; Git SHA/хеш не доказывает авторство. Три исходных ZIP из R5.3 сверялись отдельно по оригинальному SHA-256 из манифеста с уже сохранёнными локальными копиями.
- `recheck_counterexamples.py` и JSON: воспроизводимые вычисления на стандартной библиотеке Python; только искусственные математические примеры, без обучения или Android.
- `original_r53_arithmetic_replay.txt`: повторный запуск прежней проверки R5.3 (её оригинал в `source-package/EVIDENCE`). Она не является независимым доказательством всех формул и не тестирует продукт.
- `static_preflight.txt`, `static_guard_tests.txt`: прогоны для копии Android ветки `178ac32f53d1e84d44ca27475279d35113c19719`; 44 теста проверяют статический guard, не весь Android и не UDC T01–T17.
- `source_checks.json`: пересчитанные контрольные суммы, число совпадающих путей и границы выполнявшейся проверки.
