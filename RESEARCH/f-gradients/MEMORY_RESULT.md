## Findings and corrections

No mathematical contradiction in the smooth Wk/Wv chain rule was found. `bar(h)` includes both Wkᵀδk and Wvᵀδv and reaches earlier F states; shared matrix contributions are accumulated before any update (there is no update here).

Independent review found missing revocation snapshots in replay and non-informative evidence channels in the first fixture. Added a copied per-event revocation set and `Wr[0,2]=.25` with nonzero Wv row2 so OBSERVED f_e[2]=1 actually affects the read path and its tanh derivative. The first negative-control invocation correctly failed upstream but the script expected only a Wk-named failure; reordered matrix probes to check Wk/Wv first and reran. These are test/interface corrections, not hidden production fixes.

Precise FP16 counterexample is executable: around1, binary16 spacings below/above are2^-11/2^-10. Both1±1e-5 round to1, numeric derivative0 versus smooth identity derivative1. Candidate correction is an explicit smooth offline objective (implemented here) with separately evaluated export parity, or an explicitly biased STE/QAT protocol; neither is silently claimed equivalent to exact storage differentiation. No new architecture proposed.

## Remaining blockers for a full trainer

1. Full loss/target graph, joint heads, S6 policy-gradient estimator and adaptive support/halt remain outside this fixed-route path. Local gradients do not establish learning quality or convergence.
2. FP32/AMP precision, FP16 memory/storage semantics, declared quantization surrogate and export parity require their own tests. This mechanism is Double, bounded episodes≤32, not long-horizon/TBPTT proof.
3. Actual f_e schema normalization manifest and independently trusted source/receipt admission are not supplied by this fixture. Frozen supplied vectors cannot authenticate facts.
4. Real replay source snapshots must include initial state, raw canonical inputs, original routes/eligibility/revocation snapshots, boot/model version and all earlier memory dependencies. The in-memory replay demonstrates this contract but provides no durable snapshot/transaction implementation. No cross-model stale embeddings or detached hidden history is accepted as equivalent.
5. Privacy/TTL/revoke persistence, crash atomicity, representation migration and semantic-port integration; existing C1–C4 untouched. Filter tests are not Android security proofs.
6. Optimizer/projection/checkpoint/ABI, licensed datasets, independent holdouts and retention/conditioning evaluation are still needed before any separately authorized actual training.

**Next useful step:** a bounded joint supervised objective and trainer-state/checkpoint contract built on this causal graph, with explicit quantization/precision decisions. It is now reasonable to continue that implementation for existing F, not to declare UNO trained or release-ready.
