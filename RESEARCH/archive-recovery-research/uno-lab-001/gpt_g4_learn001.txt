## 1. Механизм: один организм, два масштаба обучения

Первоначальное обучение: собственные общие веса Θ на лицензионных данных, один общий оператор F, совместные текст/аудио/экран/цели/действия/память. Функции потерь Astra L3a/L4/L5 описаны, но реальные новые веса ещё не обучены.

На A52, по имеющемуся контракту R5.3: память M с точным RetrieveExact, независимый журнал подтверждений L, ограниченное изменение P только при fresh verified endpoint. Память не равна навыку; права Android остаются за доверенной границей.

Глубокое обучение E1 — новая гипотеза, не часть текущего R5.3 runtime: контролируемо изменять ограниченный срез коэффициентов внутри того же F после проверки сохранения старых задач. В ASTRA_01 Θ сейчас неизменна в runtime, поэтому E1 нельзя внедрять без отдельного решения владельца и новой редакции контракта.

## 3. Точный шаг изменения P: ASTRA_04 P1

Только endpoint a=3…23 при независимо подтверждённой бинарной метке y и frozen h, l0:

q = σ(l0 + p·h)
d_h = ε + ||h||_2^2
p' = Π_{||p||_2 ≤ 1}[ p - η * ((q-y)*h/d_h + λ*p) ]

Предкодовые defaults: ε=1, λ=0.001, η=0.01. Ручной пример h=1, l0=0, p=0, y=1: q0=0.5, dh=2, градиент −0.25, p'=0.0025, q1=0.5006249997. Нормализованный BCE+regularizer уменьшается 0.3465735903 → 0.3459489840. Это изменение предсказания на одном примере, НЕ обучение языковому понятию, НЕ глобальная успешность.

Дубликат receipt и UNKNOWN не дают второго градиента. P1/P2 доказывают локальный спад при fixed feature, а не отсутствие забывания.

## 4. Дополнительная гипотеза E1

Для одной матрицы W размера d×d внутри общего F:

W_candidate = W0 + U V^T,  U,V ∈ R^{d×r},  N_E1 = 2*d*r

Условная иллюстрация d=1024, r=8: 16 384 FP32 коэффициента = 64 КиБ; master+gradient+Adam moments по 16 B/parameter = 256 КиБ без activation, memory replay, staging. Это не утверждённый rank, не второй мозг и не гарантия качества.

Альтернативы владельцу: E1-A — на телефоне только P/M, обновление основного Θ в отдельной разрешённой офлайн-среде; E1-B — ограниченные локальные обновления общего F на A52 при RAM/energy/thermal admission. Изменение F должно проходить проекцию на norm bounds, regression gate, версионную миграцию памяти и P reset при смене features. Оба варианта REQUIRES_DATA / OWNER_DECISION.

## 5. От забывания нужен независимый gate

Контрпример: одинаковый h, противоречащие y1=1 и y2=0. Улучшение первого BCE может ухудшить второй. Поэтому:

Accept(Θ') ⇒ для всех i из R_old: ΔL_i ≤ δ_i, и HardFixturesUnchanged=TRUE

Protected replay — для отбора кандидатов, отдельный locked holdout — для оценки. Тесты: old/new/conflicting/UNKNOWN/delayed/device-state; P=0 vs P on, memory off/on, replay off/on, E1 off/on; новые формулировки и аргументы, не встречавшиеся в памяти. Сравнивать с frozen-Θ и табличным baseline. Пороги пока не установлены владельцем.
