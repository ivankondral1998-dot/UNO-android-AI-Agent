# 01. Символы, пространства и размерности

Все размеры — положительные целые, кроме допустимых нулевых квот. Вычислительная конфигурация фиксируется manifest модели. Любые входные длины ограничены до выделения памяти. Числа вне диапазона, NaN/Inf, неизвестная версия и неверная форма дают INVALID; они не становятся наблюдением нулевой величины.

## Канонический словарь

| Символ | Тип / смысл |
|---|---|
| t, τ_t, Δ_t | Номер принятого события; монотонное физическое время; τ_{t+1}−τ_t≥0 |
| k | Внутренний шаг уточнения одного наблюдения |
| n | Поколение лабораторного NCR-EVO |
| w_t ∈ W | Ненаблюдаемое физическое состояние мира; W — стандартное борелевское пространство |
| o_t ∈ O | Типизированное сырое наблюдение с источником, временем, порядком и missing-mask |
| x_t | Валидированное наблюдение; не содержит полномочий |
| K_env(dw',dΔ|w,a) | Неизвестное полумарковское ядро окружения |
| O_obs(do|w,source) | Неизвестное наблюдательное ядро |
| b_t ∈ Prob(W) | Идеальный belief; математический ориентир, не хранимый огромный объект |
| β_t ∈ [0,1]^B | Приближённые вероятности B факторов состояния; не отождествляются с b_t |
| Γ_v=(V_v,E_v) | Версионированный вычислительный граф UNO |
| Θ_v | Все медленные веса графа, включая Φ_R, входы, выходы и селекторы |
| Φ_R ⊂ Θ_v | Веса одного повторно используемого нейронного оператора |
| P_t ∈ R^{A×d} | Быстрая пластичная поправка к прогнозу исхода действий |
| s_t,h_t^k,z_t,g_t ∈ [−1,1]^d | Межсобытийное состояние, внутреннее состояние, представление, вектор активной цели |
| M_t | Ограниченный эпизодический store; не доверенная база разрешений |
| Q_t | Ограниченная очередь целей и исходных текстов |
| L_t | Доверенный журнал квитанций, дедупликации и подтверждённых наблюдений |
| U_t | Недоверенный журнал гипотез, UNKNOWN и диагностик |
| D_t | Ограниченный store ожидающих квитанций с замороженными traces |
| T_t | Состояние доверенной границы: owner, STOP, permissions, epochs, tickets |
| C_t | Вектор остаточных лимитов MAC, RAM, walltime и квот; не trusted contracts |
| G_const | Неизменяемые контракты authority, verifier, форматов и допуска |
| g^evo_n | Мутируемый геном AST/DSL; не вектор цели g_t |
| Θ_M, Φ_S | Лабораторные веса генератора и суррогата; не часть production Θ |
| E_eval | Независимый лабораторный оценщик; не encoder и не энергия |
| J_energy | Джоули; не матричные операции |

Полное состояние математической системы:

\[
X_t=(w_t,S_t,T_t,R_t),\quad
S_t=(v,\Gamma_v,\Theta_v,s_t,P_t,\beta_t,g_t,Q_t,M_t,D_t,U_t,C_t).
\]

R_t — bounded reactor с микрофазами из 02 §8; L_t принадлежит T_t. Доверенная среда не обязана быть отдельным сервисом/мозгом; это граница записываемости и capability. В этой задаче её Android-реализация не создаётся.

## Наблюдения и предложения

O — дизъюнктное объединение:

1. TEXT: до L_text=4096 токенов UTF-8 byte-fallback токенизатора, V=32768. В словарь входят все 256 байт и специальные токены; неизвестное слово кодируется, а не теряется.
2. AUDIO: PCM16 mono, расчётно 16 kHz; ограниченный ring-buffer 10 s, log-mel кадры f∈[−1,1]^80. Нормирование и missing-mask фиксированы.
3. IMAGE: ограниченные изображения, разбитые на патчи 16×16×3, f∈[−1,1]^768; число патчей ≤N_img, по умолчанию 256. Это не обещание распознавания любого экрана.
4. SENSOR: 64 нормированных координаты, включая маски пропусков; отсутствующее значение не равно физическому нулю.
5. OS_OBSERVATION: 32 признака состояния с указанием достоверности. Подписанное доказательство исполнения передаётся отдельным RECEIPT, никогда через обычный вектор.
6. INTERNAL: ограниченный токен генерации, таймер или результат памяти. Его происхождение не становится owner-командой.

Временная метка, modality, источник и маски кодируются фиксированным описанием; обучаемая проекция метаданных определена в 03. Длинный поток разбивается на токены/кадры, каждый занимает собственное событие. Итоговый лимит задачи учитывает все события, а не только последний токен.

Предложение:

\[
\hat a=(verb,args,goalId,preconditionVersion,expectedPredicate,
deadline,modelVersion,traceId).
\]

verb принадлежит конечному schema-словарю A=128; args — ограниченное дерево типизированных значений и текстовых токенов. Любой неизвестный verb или аргумент отклоняется. До 128 токенов на одно предложение, до 16 шагов плана; выход за предел — CLARIFY/ABSTAIN. Это предел одного плана, а не перечень всех способностей организма.

ExpectedPredicate строится из доверенного schema действия и проверенного пользовательского запроса. Модель может предложить желаемую величину, но не заменить критерий на тождественно истинный.

## Цели, память, знания

Цель q=(id,parent,ownerIntentRef,predicate,priority,deadline,budget,status). Только свежий ownerIntentRef или уже разрешённая его декомпозиция создаёт исполнимую цель. Самосгенерированные исследовательские подцели не создают новых полномочий.

Вектор g_t — ограниченное приближение смысла активной цели; исходный текст и predicate сохраняются отдельно. Потеря информации при компрессии возможна и подлежит оценке.

Запись M: (key∈[−1,1]^m,value∈[−1,1]^m,sourceRef,payloadRef,kind,time,expiry,modelVersion). kind∈{OBSERVED,VERIFIED_COMPLETION,CONTROLLED_EFFECT,HYPOTHESIS,USER_DECLARATION}. Достоверность записи определяется provenance в L_t, а не числом confidence в нейросети. Квота M_max=4096, m=128. Ранжирование и забывание не уничтожают доверенные неисполненные обязательства.

FIFO рабочих токенов H_ctx∈[−1,1]^{N_ctx×d}, N_ctx=256, является кэшем s прошлых событий. Он используется для обучения и доступного контекста/диагностики; базовая расчётная модель не выполняет attention по этому кэшу. Доступ к давним фактам идёт через M и исходные записи. Нельзя незаметно добавить attention без пересчёта.

## Временные шкалы и идентичности

Идентичность исполнения:

\[
\iota=(\nu,e,goalId,serial,modelVersion,proposalDigest).
\]

ν — generation доверенного runtime; e — epoch отмены внутри ν. ν никогда не читается из модельного snapshot; доверенная среда при restore/restart сначала выделяет новое ν. Предположение non-rollback-counter обозначено A_gen. При исчерпании счётчика, невозможности надёжно повысить его или утрате доверенного якоря — DENY/SAFE_MODE. Случайный UUID может дать вероятностную альтернативу, но не абсолютное доказательство уникальности.

serial, e ограничены машинным максимумом; увеличение при максимуме закрывает исполнение, а не переходит через ноль. Старые tickets не оживают после rollback. Консолидация Θ/Γ тоже меняет ν и обнуляет pending.

Шкалы: аудио 10 ms/кадр; событие — переменная Δ; нейроцикл ≤K_max; действие — deadline; online P — только квитанция; offline Θ — отдельная версия; изменение Γ — только отдельное принятие результата NCR-EVO.

## Инварианты валидной конфигурации

d кратно b=64; n_b=d/b; J≥1; χ≥1; m≤d; 0<α≤1; 0≤ρ<1; 0≤γ<1. Все квоты конечны. Инициализация s=P=0, M=D=∅; STOP=true до owner-resume. Θ принадлежит ограничениям норм из 03. Никакая численная β, память или вес не содержит capability на запись T_t.

## Фиксированные refs и отдельный payload-store

Metadata M≤64 bytes — фиксированные IDs/offset/counter поля. Переменные predicate,prestate,текст и payload: отдельный store ≤4096 объектов по ≤4096 bytes (16 MiB). Q≤64 goals, их variable данные используют этот же store. Pending metadata≤256 bytes содержит только refs, timestamps и fixed status. L≤8192 headers по128 bytes плюс refs; referenced записи pinned. При невозможности safely evict новые действия failclosed. Eviction исходника делает associated память недоступной. CONTROLLED_EFFECT требует attribution=CONTROLLED; VERIFIED_COMPLETION утверждает только predicate.

При переходах без отправки OS-действия a=∅ (явное бездействие среды). U≤8192 bounded diagnostic headers по128 bytes; variable данные используют общий payload-store. Локальные n в примере records/статистических формулах06 означают соответственно число records/paired units; поколение NCR обозначено индексом n в g_n. Их области локальны и не смешиваются с внутренним k.
