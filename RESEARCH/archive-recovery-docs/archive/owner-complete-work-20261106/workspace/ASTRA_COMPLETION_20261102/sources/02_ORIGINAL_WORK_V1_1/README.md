## Основные расчётные результаты

Один shared block-recurrent F с нормовыми ограничениями, новые Θ и отдельная ограниченная P. Базовая расчётная точка d=1024: **55 320 439** медленных параметров, ещё **131 072** пластичных чисел P. FP16 Θ:105.515 MiB; заданная mixed INT8-схема:53.131 MiB до packing/backend. Полный F:17 301 504 MAC/шаг; при K=8 —138 412 032 MAC до encoder, heads, DSP, памяти и контроля.

Сравнены d512/1024/1536/2048. Минимально достаточный размер **не установлен**. Нельзя выдать эти числа за измеренный RAM/PSS/джоули телефона.

Доказаны/выведены: ограниченность состояния; условная контракция fixed F и fair sweeps; локальный projected-gradient descent для P; арифметический бюджет при корректных upper costs; условные no-authority-escalation, stale/replay no-learn и crash-safe persistence. Для каждой гарантии выписаны предпосылки.

Найдены контрпримеры: bounded≠convergent, произвольная sparse-mask≠fairness, локальное обучение≠zero forgetting, readback≠causality, SHA≠authenticity, restore≠safe epoch, меньше MAC≠меньше джоулей, surrogate≠полезное ускорение, восстановление≠создание утраченной информации.

## Итоговый статус

**Расчётный пакет завершён; безусловный MATH DESIGN PASS всему UNO не присвоен.** Проверенные локальные обязанности имеют доказательства или явно условный статус; исходные ошибки и исправления видны в независимом заключении. Достаточное качество, минимальная размерность, A52-ресурсы, обучаемость и преимущество NCR-EVO требуют данных/устройства/отдельного исследования.

Вопрос на утверждение — формальная область и предложенные расчётные решения, а не заявление о готовом интеллекте. До отдельного утверждения нельзя переходить к новому production-коду. GitHub Actions не запускались, merge/публикации и изменения JarvisLab не выполнялись.
