# IR03–IR08: оставшиеся решения и обязательства

| ID | Математический результат | Протокольный/экспериментальный остаток |
|---|---|---|
| IR03 WAKE/SENSOR | W_wake и W_sensor существуют. В 12-строчном Astra D01 нет отдельных acceptance rows для WAKE и SENSOR | Кандидат — добавить две отдельные строки, **14 строк** вместо исходных 12 (это не число исторических 13 V2.2); определить negative/background wake windows, false-wakes/h, miss rate, energy idle, сенсорные units/masks/provenance/stale rates. Не удалять функции ради компактности. Требует data/owner thresholds. |
| IR04 OwnerGate | A_cap — внешнее trusted предположение; neural head не выдаёт consent | Предкодовый enrollment протокол: локальная идентичность owner, OS-auth с привязкой к enrolled owner, session expiry, защита confirmation от overlays, digest-bound consent, lock/profile/revoke checks, invalidation на STOP. Device credential доказывает присутствие **какого-то** допущенного device user, не автоматически владельца UNO на shared device. No owner-proof until A52 OS tests. |
| IR05 masks | 241 cyclic-prefix distinct masks, 65535 arbitrary nonempty; для q=3:16 vs560. Эквивалентности нет | Prefix = разрешённый кандидат со справедливым sampling; alternative PL допускает более широкую выборку. Выбор после одинаковой task/data/evaluation battery; не по красоте формулы. Новое W4 справедливо лишь для общих масок. |
| IR06 strict offline | Отсутствие INTERNET у UNO не запрещает remote fetch сторонним SAF provider | Строгий дефолт zero-cloud processing: app-private или доказанно локальные источники, любые сторонние provider/URI с неизвестной locality→`UNSUPPORTED_OFFLINE_SOURCE`. Даже локальный импорт не доказывает, что пользовательский файл **никогда прежде** не был из облака; заявлять только офлайн-обработку внутри заданной границы. Без отдельного согласования нельзя silently enable remote-backed sources. |
| IR07 LR2/H2 | Есть независимые численные counts, но только B2 официальный ordered tensor manifest | Для каждой рассматриваемой family нужно независимо подписанное ABI+tensor order+decoded norm certificate+parity после обученных весов. H2 cache footprint и LR2 span counterexample не выбирают качество. |
| IR08 compute | B2 d1024,128 tokens K8 nominal full event 22,457,364,480 MAC, прежние 22,011,707,392 MAC — частичная нижняя оценка F+vocab | Не включено optional RetrieveExact, platform overhead, real energy/latency. Перед устройством — calibrated primitive ledger and actual A52 tests. |

**Статус:** IR05 и IR08 арифметически прояснены. IR03/IR04/IR06/IR07 требуют owner/data/device/contracts; IR01/IR02 требуют нормативной правки математики и памяти. Ни один из этих пунктов не превращает коммерческий UNO в «маленький прототип» и не утверждает baseline.
