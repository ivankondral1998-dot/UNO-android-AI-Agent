# R5.2 / IR01 — нормативная поправка к W4 (КАНДИДАТ)

**Основание:** `ASTRA_01_FINAL_MATH_STATE_AND_DYNAMICS.md` S5–S6, `ASTRA_02_FINAL_WEIGHTS_CONNECTIVITY_AND_COUNTS.md` W4, R4 IR01, R5.1 `02_W4_CORRECTION_AND_PROOF.md`.

## Область утверждения

Пусть `T_M(h,z)_j=(1-αM_j)h_j+αM_j F_j(h,z)`, `M_j∈{0,1}`, `0≤α≤1`; при фиксированном `z` функция `F(·,z)` `γ`-липшицева в `∞`-норме, `0≤γ<1`. **Две сравниваемые траектории используют одну и ту же заранее фиксированную маску.** Тогда

`||T_M(h,z)-T_M(h',z)||∞ ≤ c_M ||h-h'||∞`, где

`c_M=max_j (1−α M_j (1−γ))`.

Доказательство: для каждой координаты треугольное неравенство даёт `(1−αM_j)|Δh_j|+αM_j|ΔF_j| ≤ [1−αM_j(1−γ)]||Δh||∞`. Максимум по j даёт оценку.

При `α=0.5`, `γ=0.9`, **полная** маска даёт `c_M=0.95`; если хотя бы один блок неактивен, `c_M=1` (верхняя оценка; она может быть достигнута). Старое утверждение `0.95^K` для произвольных sparse steps **отменено**.

## Неодинаковые z, но общий путь масок

Если отдельно сертифицировано `||F(h,z)-F(h,z')||∞ ≤ L_Fz ||z-z'||∞`, при одинаковых `M_0,...,M_{K-1}`:

`E_{i+1} ≤ c_{M_i} E_i + α L_Fz ||Δz||∞`;

`E_K ≤ (Π_{i=0}^{K-1}c_{M_i})E_0 + α L_Fz||Δz||∞ Σ_{i=0}^{K-1} Π_{j=i+1}^{K-1}c_{M_j}`.

Для постоянной неполной маски `c_M=1` сумма равна K, не разрешается подмена на геометрическую формулу с делением на нуль. Для z, зависящего от памяти, селектора, истории и параметров, требуется самостоятельная оценка этого преобразования; сама W4 её не даёт.

## Негативный результат для адаптивного селектора

`d=2, F=0, α=1/2`. Селектор выбирает `M(h)=(1,0)` при `h1>0` и `(0,1)` при `h1≤0`.

Для `h=(ε,1)` и `h'=(-ε,1)` получаем `T(h)=(ε/2,1)`, `T(h')=(-ε,1/2)`. Начальная дистанция `2ε`, конечная `1/2`, отношение `1/(4ε)→∞`. Следовательно, **нет универсальной конечной липшицевой константы для детерминированного порогового адаптивного селектора**. Это опровергает перенос оценки `c_M` на пары траекторий с разными масками.

## Fair-sweep

Если `z` постоянно, сравниваемые траектории используют один и тот же путь масок, фиксированная точка F существует и каждый блок посещён за один sweep, расстояние до общей точки после sweep не превосходит `0.95` исходного максимального отклонения при параметрах выше. Не гарантируется, что произвольные K≤8 шагов выполняют sweep; не относится к изменяющимся z, memory feedback и разным маскам.

**Статусы:** `W4_FIXED_COMMON_MASK=PROVEN_LOCAL`; `W4_ADAPTIVE_GLOBAL=FALSE_BY_COUNTEREXAMPLE`; `W4_FULL_ORGANISM_STABILITY=UNPROVEN`. Поправка не является разрешением на реализацию.
