# UNO vNEXT-R3

Начните с ERRATA_R3.md, затем ERRATA_R2.md и исправленной основной спецификации. Редакция содержит исправления, а не утверждённый baseline.

Проверка распакованного пакета: python verify_package.py. Она проверяет собственный SHA256-манифест, контрпример baseline, численный градиент и согласованность обозначений. verify_revision.py сохранён с прежним охватом; проверка старого пакета там условна на наличие соседнего uno_vnext.

Оригиналы R4.1/R53 не изменены. Авторская повторная проверка не заменяет независимый аудит, обученные веса или испытания A52.
