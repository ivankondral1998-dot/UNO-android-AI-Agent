# UNO vNEXT-R2 — исправления повторной авторской проверки

Статус: PRECODE CANDIDATE, OWNER_APPROVED_PRECODE=FALSE, PRODUCTION_CODE_AUTHORIZED=FALSE.
Это исправление последнего пакета vNEXT, не независимая сертификация и не доказательство отсутствия всех ошибок в историческом корпусе. Оригиналы сохранены. Этот файл имеет приоритет в перечисленных пунктах над vNEXT и унаследованной R4.1. Неперечисленные исторические PASS не повышаются.

## E01. Полное состояние и совместимость

Список `(s,g,P,M_exact,M_sem,G,v,clock)` был неполным: он опускал β, Θ, очереди, контекст и доверенное состояние. Норма: наследовать целиком S1 R4.1 и добавлять G; T и R остаются вне обучаемого состояния. Состояние включает версию модели, схему и версию графа отдельно.

A и B не математически взаимоисключающие. Это два раздельно исследуемых кандидата; их комбинация здесь не специфицирована. B противоречит запрету runtime-топологии R4.1 §§2,24: B является явной неподписанной поправкой к этому запрету. Slow Θ и T остаются замороженными; меняются рёбра в конечных слотах. Это не произвольный рост числа нейронов. Реализация любого кандидата пока не разрешена.

## E02. Обновление графа не является P1

Обозначить веса графа W_G, сохранив P∈R^{128×d} и его 21 разрешённую строку. Нельзя наследовать доказательство P1 на новый update.

Для одного фиксированного примера f(w)=log(1+exp(wᵀu))−y wᵀu, y∈{0,1}. Hessian = σ(1−σ)uuᵀ, значит L≤||u||₂²/4. Для box C=[−wmax,wmax]^p, w∈C, w′=Π_C(w−η∇f), η>0, проекционное неравенство даёт ∇fᵀ(w′−w)≤−||w′−w||²/η. Поэтому

f(w′)≤f(w)−(1/η−L/2)||w′−w||².

При ||u||₂≤U, U>0 и 0<η≤8/U² потери этого примера не растут. При η=0 или u=0 — identity. Это CONDITIONAL, а не доказательство улучшения всей задачи: противоположная следующая метка может повысить старую потерю.

Commit требует независимо допустимой метки, отсутствия STOP, действующих consent/epoch/model-version, дедупликации и cap в одной сериализованной транзакции. Иначе W_G, support/contradiction и G не меняются. UNKNOWN не превращается в отрицательную метку. Обновление счётчиков и исключение дубликата атомарны с записью веса. Журнал наблюдений подчинён отдельной политике согласия.

## E03. Вариант A: кодирование, цена, градиент

Фраза «trainable lookup через существующий бюджет» не определяла ни тензор, ни градиент. Для минимального кандидата убрать этот lookup: e(record)∈R^m — фиксированное кодирование, ||e||∞≤1, схема с digest. Конкретный допустимый пример: одна координата H1(record) mod m со знаком из H2(record), остальные нули. Это коллизионное представление, НЕ доказанная семантика. Обучаемое кодирование требует отдельного реестра тензоров.

При v_i=clip(w_iᵀu_i,−1,1)e_i и g_G=Σω_i v_i имеем ||g_G||∞≤1. γ конечна и фиксируется manifest. Wr получает r+γg_G одним matvec; дополнительного dm MAC тогда нет. Два отдельных matvec добавляют dm. Стоимость запроса сортированного массива из E записей по c диапазонам: O(c log(E+1)+Q+R(m+p)), плюс ограниченное декодирование байтов; вставка O(E), staging O(E). Ограниченный scan не обещает глобальный top-R.

Для upstream a по z_A: a_G=γ Wrᵀ[a⊙(1−z_A²)], затем ∂L/∂score_i=ω_i a_Gᵀ(v_i−g_G). При |w_iᵀu_i|<1: ∂L/∂w_i=ω_i(a_Gᵀe_i)u_i, только если offline граф включён в differentiable unroll. На границе clip нужна объявленная subgradient-конвенция; online update задаётся E02, а не этим градиентом. Исторические detached records не обучают writer.

При γ=0 обходить граф до чтения: формальное 0·NaN не восстанавливает baseline. Алгебраическое равенство ветвей не устанавливает битовое parity: требуется одинаковый порядок операций и проверка реализации.

## E04. Вариант B: формы и устойчивость

Для блока j и ветви l: h_i∈R^b, A_lj,C_lj∈R^{r_u×d}, B_lj∈R^{b×r_u}, T_r∈R^{r_u×b}; в исходной семье r_u=χb. Для LR2 A,C означают произведения факторов. Δ_j=Σ_{e:i→j}c_e T_type(e)h_i, u_lj=tanh(A_lj h+C_lj z+a_lj+Δ_j), F_j=Σ_l tanh(B_lj u_lj+b_lj)/J. Все ветви читают одно старое h. T общие по типам, не отдельные мозги.

Прежнее β_e переименовать в c_e: β уже обозначает belief. Контекст и c_e фиксируются на unroll. Кандидат коэффициента c_e=clip(w_eᵀu_e,−1,1). Пусть S_j=Σ_e |c_e| ||T_type(e)||∞. При S_j>0 умножить c_e на min(1,δ/S_j); при S_j=0 ничего не менять. Тогда ||Δ_j(h)−Δ_j(h′)||∞≤δ||h−h′||∞.

При ||B_lj||∞(||A_lj||∞+δ)≤q<1 и 0<α≤1 коэффициент активного блока ≤1−α+αq, неактивного ≤1. All-active даёт сжатие при одинаковых z, графе, коэффициентах и маске. α=0 даёт identity. Для state-dependent выбора доказательство не действует.

При исходных насыщенных caps A=1,B=0.9 и сохранении q=0.9 запас δ равен нулю. Для ненулевого графа требуется уменьшить нормы A/B или пересчитать новый q<1; при прежних A/B допустимо δ<1/9. Это выбор кандидата, не утверждённый cap. Например δ=0.05 даёт q=0.945 и при α=0.5 коэффициент 0.9725, хуже базового 0.95.

Дополнительные параметры T: N_types·r_u·b. Прямой расчёт без кэша ограничен KJa d_in r_u b матричных MAC и KJa d_in r_u взвешиваний. Это верхняя оценка повторного расчёта, а не оптимальный минимум: одинаковую Δ_j можно вычислить один раз для всех J. Учесть нормы/проверки, индекс, staging и публикацию. Градиенты при frozen c: ∇T_r += c_e d_u h_iᵀ, ∂h_i += c_e T_rᵀd_u, с суммой всех применений. Если c или нормирование зависят от T в текущем forward, эти формулы неполны: требуется полное цепное правило либо явно detached коэффициент.

## E05. Исправленная graph ABI

56+4p было верным размером перечисленных полей, но список не содержал lifecycle, boot, consent и generation концов. Поэтому он не задавал заявленную безопасную запись. Новый КАНДИДАТ fixed record, little-endian, без native padding:

| Offset | Поле | Размер |
|---:|---|---:|
| 0 | id, generation, expiry, evidence_ref (4×u64) | 32 |
| 32 | src,dst,context (3×u32) | 12 |
| 44 | relation,flags (2×u16) | 4 |
| 48 | support,contradiction (2×u32) | 8 |
| 56 | state u8, reserved zero | 8 |
| 64 | boot_epoch,consent_epoch,src_generation,dst_generation,observed_at (5×u64) | 40 |
| 104 | weight[p] float32 | 4p |

stride=align8(104+4p). При p=32 это 232 байта против прежних 184; E=4096 даёт 950272 байта только records, на 196608 больше прежнего расчёта. Это пример, не выбранная квота. Snapshot header хранит schema, p, n_types, caps, model version, namespace, dictionary digest и content digest; его канонический бинарный формат ещё не определён (SPECIFIED_UNTESTED/BLOCKED_ABI_EXPORT). evidence_ref — ссылка на immutable evidence store с проверкой generation/digest и политики, а не право доступа. State enum: proposed=0, observed=1, corroborated=2, contested=3, expired=4; неизвестный enum отвергается. Expiry/observed_at читаются только в совпадающей эпохе. CSR slots и index memory считаются отдельно; граф B требует валидности src/dst как block indices. Общая запись A может ссылаться на типизированные event/features, поэтому нельзя автоматически интерпретировать её как B edge без явного отображения.

Если все slots защищены активными ссылками/retention reserve, вставка возвращает CAPACITY_REJECTED. Нельзя бесконечно вытеснять или превышать cap. Это отказ адаптации, который учитывается в метриках.

## E06. Авторизация и доказательства

O01 не разрешает снимать обязательные WAKE/SENSOR: полный объём задан владельцем, возможна только последовательность реализации. O03 — сравнение кандидатов, не назначение архитектуры. O07 «подтверждение каждого действия» и «ограниченные полномочия» — варианты после enrollment/threat-model, не замена идентификации владельца. Предкодовый G4 не требует заранее получить trained weights/A52 PASS; он требует согласованного контракта, выбранной области и процедуры порогов. G5 разрешается отдельно.

Фонарик: если независимый физический oracle отсутствует, callback доказывает лишь свой контракт. Источник Android API и устройство в этом исправлении не исследовались; аппаратный успех не заявляется.

Верхняя односторонняя граница частоты ошибок при 0 из N iid Bernoulli и уровне 1−a равна 1−a^(1/N). Для зависимых повторов/адаптивной остановки она неприменима без нового анализа. FAIL отсутствия сравнительного выигрыша не означает невозможность обучения.
