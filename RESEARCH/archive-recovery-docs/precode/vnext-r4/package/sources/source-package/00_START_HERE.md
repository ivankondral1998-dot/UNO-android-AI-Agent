# UNO R5.3 — полная составная предкодовая редакция (кандидат)

**Дата:** 2026-11-02. **Статус:** `PRECODE_CANDIDATE_FOR_OWNER_REVIEW`.
**OWNER_APPROVED_PRECODE = FALSE. PRODUCTION_CODE_AUTHORIZED = FALSE.**

Это **не R5.4**, не новый дизайн с нуля и не сертификат правильности всей математики. Это редакционно согласованная *составная* R5.3, которая сохраняет первичные тексты Astra целиком и добавляет открыто названные поправки R5.1/R5.2/R5.3. Математические доказательства внутри источников сохраняют свои исходные ограничения.

## Читать по порядку

1. `NORMATIVE/01_SOURCE_HIERARCHY_AND_CONTRACT_INDEX.md` — приоритет документов, разногласия, термины и карта подсистем.
2. `NORMATIVE/02_FORMAL_CORRECTIONS_AND_LIMITS.md` — точные замены неверных claims W4, памяти, обучающих/аппаратных claims.
3. `NORMATIVE/03_CONSOLIDATED_SUBSYSTEM_CONTRACTS.md` — указатели на **полные** исходные формулы и новые уточнения; ни одна короткая формула не заменяет оригинал.
4. `NORMATIVE/04_ALL_GATES_D_X_B_M.md` — индивидуальные D01–D10, X01–X12, B01–B14, M01–M44.
5. `NORMATIVE/05_OWNER_DECISIONS_AND_FUTURE_EVIDENCE.md` — что вправе утвердить владелец и что проверяется только позднее.
6. `NORMATIVE/06_VERIFICATION_BOUNDARIES.md` — выполненные проверки, невыполненные тесты, критерии честной приёмки.
7. `NORMATIVE/07_EXPLANATION_FOR_OWNER.md` — русское объяснение для владельца.
8. `SOURCES/ASTRA_CURRENT/ASTRA_01...12` — **полные** математические документы; `SOURCES/ASTRA_FINAL_UNMODIFIED.zip` — исходная неизменённая публикация с доказательствами и машинными реестрами.

## Как пользоваться

Этот пакет не переписывает оригинальные Astra-исходники. Если внутри исходника осталась позднее опровергнутая формулировка — правило устранения коллизии указано явно в `01` и `02`. Готовность B2 как обученной и проверенной модели **не следует** из тензорных форм.

Папка `SOURCES` является доказательной базой и историей, а не несколькими параллельными конкурирующими спецификациями. `SHA256_MANIFEST.json` намеренно **не хеширует сам себя**. Внешний SHA-256 ZIP публикуется отдельно.

Не выполнять GitHub Actions, не модифицировать код/репозитории, не начинать обучение и не утверждать baseline без решения владельца.
