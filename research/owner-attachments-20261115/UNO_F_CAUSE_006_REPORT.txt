INTERPRETATION: For r1 single slot, an external explicit WRITE gate restores
trainability of original constrained F under this isolated CPU experiment.
But it makes the sequence-length task trivially persistent: if only one write
happens, state no longer changes after that write. This is NOT evidence that
F can process unrelated events and preserve separate information in the same state.
