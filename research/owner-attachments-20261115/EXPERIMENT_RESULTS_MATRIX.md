# UNO F/S4 — проверяемая матрица результатов (001–007, TRAIN-001/002)

**Область:** конкретные исходные эксперименты владельца, не вся архитектура UNO. Содержимое восстановлено из оригинальных ZIP и сверено с отчетами `research/train001`, `research/train002`. Числа из исторических логов имеют статус **SOURCE_REPORTED**, пока не выполнена независимая репродукция. Нет проверки на Android, нет обучения production-весов.

**Ветка исследований:** `research/uno-train-001-s4-20261115`. Обязательные ограничения и разрешения: актуальный корневой `AGENTS.md` ветки `main`. Не создавать веток, не запускать Actions.

## Различайте три принципиально разных эксперимента

1. **005B:** исходная рекуррентная `UnoF`, **без обучаемого адресного банка S4**. Это **негативный результат**: длительная память на пяти синтетических задачах не обучилась. GRU в том же исследовании работала лучше. Нельзя выдавать 005B за успешное обучение S4.
2. **007:** внешний по отношению к состоянию F банк с **заданными ключами и кодировками**, замороженным исходным F; учились только `Ug/Wq/Wr` и выходная голова. Высокий результат показывает полезность доступного адресного чтения, **но не обучение Wk/Wv и не полноценную пластичную S4**.
3. **TRAIN-001:** F + **обучаемые Wk/Wv** и bank на эпизод; подтверждена CPU-переоценка сохранённого checkpoint. Однако inference `memory_off` не является честно обученной моделью F-only. TRAIN-002 только подготовил контролируемое сравнение.

## Как читать и сверять исходники без большого 005B ZIP

Восстановление текстов из **девяти уже сохранённых** оригинальных ZIP:
```sh
python3 research/owner-attachments-20261115/extract_research_sources.py \
 --archives research/owner-attachments-20261115/original-zips \
 --manifest research/owner-attachments-20261115/ARTIFACTS.tsv \
 --out /tmp/uno-study-texts-new
```
Скрипт сверяет исходные ZIP по SHA-256, CRC, сохраняет отдельные каталоги по экспериментам и пишет `RESEARCH_SOURCES_MANIFEST.json` с SHA-256 каждого извлечённого текста. Он не извлекает веса, не изменяет Git, не создаёт веток и не делает новых экспериментов. Большой оригинал 005B **не нужен для чтения 48 программ**, но его 47 промежуточных optimizer checkpoints этим способом не восстанавливаются.

**Текущее правило владельца:** не загружать большой 252-МБ архив 005B в Git ради дублирования исследований; сохранить доступность важных материалов и точную информацию об отсутствующих весах. Оригиналы остаются неприкосновенными. Указатель `-` в ARTIFACTS.tsv означает, что соответствующий ZIP не найден как самостоятельный Git blob, а не обязательно отсутствие всех его программ.
