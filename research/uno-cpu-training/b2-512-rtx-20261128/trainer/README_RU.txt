UNO B2-512 CUDA research bridge — 28.11.2026
Это новая исследовательская фаза существующей B2-512 R5.4 Candidate, не новая архитектура и не production.
Источник: UNO_B2_512_LANGUAGE_STEP000050_RESUME.zip. Вложенные latest.uno, tokenizer.json и model_original.py — оригинальные байты. Оригинальные веса 50 шагов загружаются, Adam запускается заново, поскольку изменился корпус и устройство. Не точное возобновление прежней фазы. Математический переход сохранен; model.py выбирает embedding всей последовательности за один gather, вместо отдельных gather по токенам. CPU parity d128: forward exact, max gradient delta 0 на двух примерах. Полная B2-512: CPU 3 updates, включая masked dialogue. 23 015 887 выделенных параметров, 514 активных ID из 32768. Не все параметры обучаются. S4 bank пуст, нет записи в память, S6 фиксированный маршрут K1, нет Android actions/голосового обучения. Это только языковая фаза. Нет заявлений о качественном диалоге.
Распаковать в D:\UNO\b2_cuda_bridge. Дождаться завершения CORPUS_PREP FIX03; нужен D:\UNO\corpus_prepared_v3 (не .building). Не менять среду Python. PowerShell:
& "D:\UNO\env\Scripts\python.exe" "D:\UNO\b2_cuda_bridge\train_cuda.py" probe
CUDA probe не сохраняет новые веса. Проверяет реальные train updates и validation, контролирует GPU <78 C и <6500 MiB. Только успешный GPU probe создает привязанную к исходникам, данным и устройству квитанцию. Не запускать train до согласования результатов замера.
Train/resume: отдельные явные команды с --minutes; выбираются после замера. Resume требует тот же config и cuda-probe.json. Latest и best сохраняются атомарно с SHA256, optimizer, RNG, history. Новые веса лежат D:\UNO\b2_cuda_run. Lock после аварийного убийства требует отдельной проверки, прежде чем его убрать. Системный crash/power loss, Windows, CUDA и точное возобновление на CUDA не проверены. CPU probe ограниченный; тесты на демонстрационном корпусе FIX03, а не на скачанных 8.31 ГБ. Validation случайная детерминированная выборка окон, не полный holdout. Locked test не используется для loss/выбора модели. Обучение языка и ответов ассистента; не обучение действиям. Контекст по умолчанию 32 токена, разбиение на окна сбрасывает состояние, ограничение длинного контекста. Режим research: корпус содержит источники с нерешенными коммерческими правами, не допуск продукта. Исходная математика, GitHub, Android и старые веса не менялись.
