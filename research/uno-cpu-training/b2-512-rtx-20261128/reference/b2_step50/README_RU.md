## Размер и реализация
Оригинальная Astra ASTRA_02 рекомендует сначала B2-512, затем B2-1024 (55 451 639 параметров). B2-512 — 23 015 887 выделенных scalar slots, 22 852 753 free, 163 134 frozen, 118 tensors. `d512,m128,V32768,b64,chi4,J2,nb8,Kmax8`. В этом испытании K=1, все 8 блоков, selector не обучается. Один общий S4/S5 с tied E, тот же математический оператор, не трансформер; вычислительное ядро векторизовано без новых параметров. При d128 сверено с прежней реализацией на двух наборах (пустая память/3 записи, K2), максимальное FP32 расхождение состояния 0, проверка causal prefix PASS. Это локальная проверка, не доказательство полного R5.4. Нет полного S6/допуска бюджета, S1/S2/S3/S7, production ABI/Android. Веса ненужных голов выделены, но не обучаются. Память S4 имеет путь чтения, на данном языковом этапе банк пуст; нет записи в память. Не общее T1 по Astra (нет аудио, изображения, синтеза речи). 50 шагов, CPU, 3 threads, PyTorch 2.10.0+cpu. Adam .001, фиксированный research route/объектив и LR отличны от полного T1 curriculum. Контекст 16 токенов, 4 окна в batch, clipped grad norm1, row-L1 projected Adam, ограничения проверяются на фактических FP32 числах. Число параметров не оценка интеллекта.

## Данные
Четыре оригинальных произведения Чехова и Горького из `https://github.com/d0rj/RusLit`, проверенные Git blob SHA-1 и SHA-256 в `corpus_manifest.json`. Чтение публичного GitHub через доступный API; прямое скачивание большого корпуса недоступно (DNS fail). Заявление репозитория: общественное достояние; права конкретного издания и юрисдикции проверять отдельно до коммерческого использования. 2 произведения train (10409 bytes, 3167 токенов с BOS/EOS), одно dev (492 предсказания), одно reserved не токенизировано и не оценивалось. Маленький эксперимент, не полноценный языковой корпус. Детерминированный byte BPE только train, 256 merges, byte fallback, BOS/EOS, 514 active ids; 32768 слотов в E выделены, незаполненные/невалидные id маскированы в head. Не утверждённый production tokenizer32768. На dev видны только известные правила токенизации, не leakage из train; разбиение по целым произведениям. Полный T0/A03 отсутствует.

## Результат
50 optimizer updates, 3200 предъявлений целевых токенов с повторениями, без гарантии покрытия всех train токенов. Dev NLL: шаг0 6.241836, шаг10 5.812752, шаг20 5.787295, шаг30 5.802372, шаг40 5.757414, шаг50 5.779394. Dev perplexity 513.80 -> 323.56; accuracy step50 8/492 (1.63%). Сглаженные unigram 330.54 и bigram 218.14 perplexity. Модель не обошла bigram. Никаких доказательств знания языка, генерации правильных ответов или достаточности размера B2-512. Изменилось 4 696 038 координат в 86 тензорах (из 118). Adam state в 88 тензорах; нулевой grad в части tensor не означает обученность. Все 118 тензоров finite и decoded caps, frozen rows/moments проверены. Полные метрики и stdout приложены. Малый корпус и короткий контекст — ограничения; остановлено после 50 шагов на плато dev. Дальнейшее увеличение размера/повторное обучение того же крошечного корпуса не обосновано. Нужен крупный legal train/dev/locked corpus по независимым произведениям, полноценный токенизатор, новый versioned trial. Не использовать reserved для выбора модели. После расширения словаря потребуется совместимая миграция embedding с фиксированными id или отдельный эксперимент с нуля; молча менять tokenizer нельзя.

## Восстановление
Распаковать в отдельный каталог. Linux: `sha256sum -c SHA256SUMS`. Python 3.13, PyTorch 2.10.0+cpu. `python train.py --resume --steps 10 --eval-every 10`. `latest.uno` включает веса, Adam, конфиг/хеши исходников и данных, шаг/позицию, Python и Torch RNG, историю. Загрузка `weights_only=True`, отказ при несоответствии источника/конфига. Каждые 10 шагов и в конце атомарный fsync/rename. Новая версия source/config требует явно версионированной фазы. Запуск не фоновый; сохраняются только фактически записанные и внешне сохранённые контрольные точки. Не обещается битовое равенство между разными устройствами и версиями ПО. `python parity.py` проверяет исходную fixed-route parity/causality. Не запускайте `tokenizer.py` при resume: данные уже сохранены. Веса только исследовательские; не устанавливать в UNO Android.
