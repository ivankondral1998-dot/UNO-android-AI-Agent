# UNO-N0-07 — Tiny Shared-F Neural Organism (isolated research, 2026-11-05)

This is a **new, functioning, tiny Java neural research implementation**, not the approved UNO production architecture. It was built in response to the owner request for a neural network about the scale of the N0-04/N0-05 Android tests, based on the UNO mathematics and Grok's corrected minimum-organism paper. The Grok source here was PAPER, not verified runnable code. The design adapts *selected* formulas and assumptions rather than claiming faithful implementation of the entire R5.3 system.

## What is actually implemented

- One shared bounded state `s∈[-1,1]^16` and one shared block-recurrent neural operator `F` with 4 blocks, 2 active blocks per pass, 2 passes/event. Inactive matrix kernels **are skipped** in source, not computed and zeroed. `h0=(s+z)/2`, `z=tanh(Ef+U_s s+semantic memory)` and `h+=(1−αM)h+αMF` with `α=.5`.
- `J=2` tanh branches per active block, expansion `χ=2`, block width 4, deterministic cyclic-two-block selection. **This is NOT the full sampled R5.3 cyclic-prefix/halting policy**, nor a proven globally contracting adaptive operator.
- 2,917 newly initialized scalar trainable parameters (`Θ`): input encoder 176, state coupling 256, F matrices 2,304, F biases 96, sensor head 51, owner-intent head 34. Online training uses a three-class next-window sensor cross-entropy loss with **event-local backpropagation through the two actual executed F passes**, plus a separate explicit owner-intent head trained only from user corrections. Runtime training of small Θ is an isolated E1 lab experiment, NOT adopted R5.3 S1.
- Typed exact FIFO ledger of 96 entries with `COMPLETE`/`TRUNCATED`/`UNKNOWN`, and a separate lossy eight-observation semantic summary. User explanations remain distinct from `ANDROID_SENSOR_OBS`; neither is permission.
- `MockTicket` / `MockReceipt`-gated bounded P-style plasticity on **synthetic verified-outcome fixtures only**: rejected STOP, missing/stale, unknown, mismatched and duplicate receipts; one matching mock receipt can update a norm-bounded row. No actual native Android action, permission or readback is implemented.
- Deterministic checkpoint serialization, SHA-256 envelope, restored state/weights/memory and prevention of mock ticket replay across restore.
- Minimal Android Activity source for Samsung A52 with TYPE_LINEAR_ACCELERATION (accelerometer/gravity-filter fallback), five-stage 80-window A/B/A experiment, buttons for owner meaning corrections during learning, transparent Markov/persistence/always-STILL baselines, owner STOP, explicit reset confirmation, local SHA-256 checkpoint and trace export. **NO installable APK built in the available environment.** Package `org.unovyra.n007`, distinct from N0-04 and N0-05; no INTERNET or other manifest permissions.

## Host replay, reproducible

With JDK 8+:

```sh
./run_host.sh
```

This compiles the core and frozen original N0-05 comparator (verbatim private source from user's bundle, with compile-only `org.json` stubs) and executes thousands of deterministic checks plus a synthetic five-stage A→B→A comparison. JDK21 run output is saved in `results/host_run_final_1.txt`, `results/host_run_final_2.txt`; byte-for-byte identical. You can also run the self-contained Java 8 bytecode JAR:

```sh
java -jar UNO_N0_07_HOST_EXPERIMENT.jar
```


Builds and locally signs a **temporary research APK** from the standalone Java source; avoid using its ephemeral signing key for commercial releases.
